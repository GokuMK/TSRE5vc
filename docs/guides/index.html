Elevation and imagery

Guide What you will learn
Elevation data Load terrain heights, choose a fallback, and add WCS, COG, STAC or local GeoTIFF sources.
Imagery data Load aerial photographs and satellite imagery, and add WMS, WMTS, STAC/COG or static-map URL sources, including Google Static Maps.

Custom source definitions belong in assets/geo/ in your TSRE working directory, normally beside TSRE5vc.exe. The guides explain the exact filenames; TSRE does not scan that folder for arbitrary JSON files. Downloaded raster data belongs in the separately configured geodata directory.

For implementation history and source surveys, see the geodata development documentation.
