# Task 02 - Flexible Track

## Objective

Define and implement the next stage of flexible-track editing.

## Status

Proposed. Detailed behavior, supported track layouts, editor workflow, and
acceptance criteria are still to be specified.

## Existing Foundation

- Task 01 contains the current Flex/AutoFlex two-curve implementation and
  its test infrastructure.
- Reuse the existing Flex geometry and regression tests where appropriate.
- Keep this task separate from the archived grouped-`TrackShape` experiment
  under `docs/tasks/groupobj`.

## Scope To Define

- How the user creates or edits a flexible track.
- Which endpoints and source objects are supported.
- Expected behavior for straight, curved, elevated, and rotated inputs.
- TDB insertion and update behavior.
- Required editor visualization and controls.
- Automated acceptance cases.
