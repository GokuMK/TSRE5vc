# Fonts of TSRE's own documents

Noto Sans regular and bold, version 2.015 (unhinted TrueType: TSRE draws
glyphs from their outlines), from the Noto project's release
https://github.com/notofonts/latin-greek-cyrillic/releases/tag/NotoSans-v2.015
(`NotoSans-v2.015.zip`, SHA-256
`0c34df072a3fa7efbb7cbf34950e1f971a4447cffe365d3a359e2d4089b958f5`). Latin
(Polish included), Greek and Cyrillic. SIL Open Font License 1.1, see
`OFL.txt`.

Every font file in this folder is loaded when the UI starts.
